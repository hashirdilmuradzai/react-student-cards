# React Student Cards

A simple React project that displays student information in individual cards using JavaScript arrays and the `map()` method.

## 🚀 Features

- Display multiple student cards
- Show student names
- Display course information
- Show student age and city
- Dynamically render cards from an array
- Clean and organized card layout
- Responsive design

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- JSX
- HTML5
- CSS3

## 📚 Concepts Practiced

- React Components
- JSX
- JavaScript Arrays
- `map()` Method
- Dynamic Rendering
- Props
- Component Reusability
- CSS Styling

## 🎯 Assignment Objective

The purpose of this assignment is to practice rendering multiple UI elements in React using the JavaScript `map()` method and understand how to display dynamic data through reusable components.
